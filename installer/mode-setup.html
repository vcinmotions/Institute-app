Standalone Mode (single computer)

Everything runs on this computer and the database is stored here. No network or internet is needed for normal work.

Centralized LAN Mode - this computer is the Server

This computer hosts the database and services. Other computers in the institute connect to it, so everyone shares the same data.

Ports used: 5001 (backend) and 3000 (app). Keep this computer on while others work.
Centralized LAN Mode - connect to a Server

This computer has no database of its own. It uses the server computer's data (Desk Manager, Faculty and other staff PCs).
